سكريبت مكتوب بلغة **Bash / Shell** يقوم بأخذ نسخة احتياطية من MySQL، ضغطها، رفعها إلى سحابة AWS S3، وحذف النسخ القديمة التي مر عليها أكثر من 30 يوماً.



---

### كيفية جعل السكريبت يعمل تلقائياً كل منتصف الليل؟

لتشغيل هذا السكريبت أوتوماتيكياً دون تدخل منك، يمكنك جدولته عبر أداة `Cron` في نظام لينكس:

1. افتح محرر الجدولة للأمر بإدخال التالي في التيرمينال:
```bash
crontab -e

```


2. أضف السطر التالي في نهاية الملف (مع تعديل المسار ليكون مسار السكريبت الحقيقي لديك):
```bash
0 0 * * * /bin/bash /path/to/your/backup.sh >> /var/log/mysql_backup.log 2>&1

```


(هذا الأمر يعني: في تمام الساعة 12:00 منتصف الليل كل يوم، قم بتشغيل السكريبت وحفظ سجل العمليات في ملف Log محدد لتتمكن من مراجعته لاحقاً)
